# 疯狂水世界 · 广告还原版

把抖音上刷屏的《疯狂水世界》广告，真的做成了能玩的网页游戏：甩钩捞垃圾、扩建木筏、打鲨鱼，从「五级小木筏」一路建成「海上豪宅区」。

- **在线玩**：https://nimble-snickerdoodle-21ff2e.netlify.app
- **本地玩**：下载 `dist/index.html`，双击用浏览器打开，不用联网、不用装任何东西
- 电脑和手机都能玩，进度自动存在玩家自己的浏览器里

> 这是粉丝向的恶搞同人作品，非官方、非商业。「疯狂水世界」及相关广告梗归原权利方所有。

## 玩法

| 操作 | 电脑 | 手机 |
|---|---|---|
| 甩钩捞东西 | 点海面 | 点海面 |
| 坐红澡盆出海扫货 | 点钩子够不着的远处 | 同左 |
| 扎鲨鱼 / 修木板 | 点鲨鱼 / 点咬坏的木板 | 同左 |
| 建造 | 点下面的建筑卡片，再点木筏 | 选卡片后点亮起的格子 |
| 拆除（全额返还） | 选「🔨 拆除」或按 0 | 选「🔨 拆除」 |
| 转视角 / 缩放 | 按住右键拖动或 Q / E / 滚轮 | 单指拖动 / 双指缩放 |
| 取消 / 暂停 | 右键单击或 Esc / 空格 | 点提示条 / 右上角按钮 |

内容一览：开场剧情（肥强被赶出高级庇护所）、开局「快问快答」三选一、12 种建筑、5 级庇护所、坐骑（红澡盆 → 摩托艇 → 游艇）、阿水们自动甩钩、哈吉米、黄金棒、鲨鱼群、每 5 天一个 Boss（肌肉佬翡翠蟹 / 王总收租船 / 深海巨兽 / 老板黄金战舰）、阴天 / 下雨 / 暴雨、沉没的城市、肥强头顶台词、海浪雨声环境音。

## 怎么改

```bash
# 1. 改 src/ 下的源码
# 2. 打包成单文件
python3 build.py          # 生成 dist/index.html
# 3. 自动测试（需要装 Chrome）
python3 tools/smoke_test.py
# 4. 双击 dist/index.html 自己玩一下
```

只用到 Python 3 自带的库，不需要 npm、不需要装依赖。

## 怎么发布

1. 登录 https://app.netlify.com ，进入站点的 Project overview
2. 把 `dist` 文件夹拖到页面上「Already built it?」那个虚线框里
3. Activity 里出现新的 Published 就好了，网址不变，玩家刷新即可，存档不受影响

注意：不要去 `app.netlify.com/drop` 拖，那会新建一个站点、换一个网址。

## 目录

```

src/index.template.html     页面结构、样式（含手机适配）、两个占位符
src/js/01-core.js           基础工具、数据表（建筑/等级）、音效、场景、海面、贴图、所有 3D 模型
src/js/02-gameplay.js       玩法：木筏格子、漂浮物、钩子、鲨鱼、炮台、建造/拆除、升级、天数、阿水、哈吉米、坐骑
src/js/03-ui.js             特效、HUD、输入（鼠标+触屏）、镜头、天气、昼夜、存档、主循环
src/js/04-story.js          环境音、开场剧情、肥强台词气泡
src/js/05-boss.js           Boss：肌肉佬翡翠蟹、王总收租船、深海巨兽、老板黄金战舰

tools/smoke_test.py         无头 Chrome 冒烟测试

```

## 技术

纯原生 JavaScript + [Three.js](https://threejs.org/)（WebGL）。没有游戏引擎、没有前端框架、没有图片和音频文件：模型用基础几何体拼，贴图用 canvas 画，音效用 Web Audio 实时合成，开场剧情是 3D 场景实时演出。存档用 localStorage。
